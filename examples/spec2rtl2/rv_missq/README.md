# The instruction-fetch miss queue — the regeneration run

The first entry built twice through the ladder: once to prove the route, then cleared to
its specification and rebuilt rung by rung (2026-08-31), every artifact regenerated by the
current tools and every rung user-approved. `ladder.yaml` is the record of that process.

| file | what it is |
|---|---|
| `SPECIFICATION.md` | the English in force: P1–P17, A1–A5, the traceability table |
| `rvMissq.yaml` | the signature — the compiler's symbol table; defaults are the proven configuration |
| `rvMissq.cnl` | the specification in controlled English (the user's draft, corrected, sigiled) |
| `rvMissq.cnl.core` | its desugared symbolic core — generated, committed, never hand-edited |
| `spec.lp` | THE CONTRACT OF RECORD: compiled from the two files above |
| `specFv.lp` | the FV stand-in's hand-written contract — this entry's two-producer parity fixture (per-entry, not a route requirement) |
| `generate.py` → `l1.lp`, `l1.inv.lp` | the design (lanes under `depth`, `xxM1` staging, one rotating arbiter for both ports) and its linkage, mounting both contracts' vocabularies on the same flops |
| `CERTIFICATE.md`, `certificate.log`, `certificateFv.log` | what the proof establishes, and both runners' raw reports |
| `rvMissq.sv` | the printed RTL — parametric, grouped generate-for, `xx[i] <= xxM1[i]`, thresholds as parameter expressions |
| `roundtrip_scenario.lp` | the scripted story the round trip and Icarus compare on |
| `ladder.yaml` | the seven rungs, each built → explained → approved by the user |

Reproduce the certificate from this directory:

    PYTHONPATH=../../../src python -m sv2asp.aspfirst2 refine spec.lp l1.lp --induct 1

and the round trip:

    PYTHONPATH=../../../src python -m sv2asp.aspfirst2 roundtrip l1.lp roundtrip_scenario.lp --icarus
